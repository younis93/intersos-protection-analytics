# Iraq Data Analysis 1.0.57

## Introducing Kobo Analysis

Kobo Analysis brings survey preparation, interactive analysis, and professional reporting into one integrated workspace.

- Import Kobo XLSForms and Excel or CSV response exports, review data quality, and manage survey projects locally.
- Explore results through interactive charts, pivot tables, filters, group comparisons, and configurable indicators.
- Open the response records behind results and save analysis views for consistent reporting.
- Plan survey coverage with the sample size calculator, including optional location and gender breakdowns.
- Share findings through formatted Excel workbooks, PDF reports, and structured AI report prompts.

Survey files and response data remain on the user's computer.
